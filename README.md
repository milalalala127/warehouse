# Учёт товаров на складе

## Постановка задачи: «Учёт товаров на складе»

**Предметная область.** Учёт товаров на складе торгового предприятия. В системе учитываются товары, их количество на складе, приход и расход.

**Цели системы.** Автоматизировать учёт поступления и списания товаров, контролировать актуальные остатки на складе, формировать отчёты о товарах, которых осталось мало.

## Пользователи системы

- **Кладовщик** — оформляет приход и расход товара, ищет товары, просматривает остатки.
- **Администратор** — управляет справочником товаров, формирует отчёты.

Все пользователи обязаны авторизоваться.

## Основные функции системы

- авторизация пользователей;
- просмотр списка товаров и остатков;
- оформление прихода товара;
- оформление расхода (списания) товара;
- поиск товара по названию;
- добавление товара в справочник;
- удаление товара из справочника;
- формирование отчёта «мало на складе».

## Архитектура и реализация

Архитектура многослойная: уровень интерфейса, уровень логики и уровень данных. Реализация предполагает использование языка программирования C++, хранение данных в текстовом файле, интерфейс — в виде консольного приложения.
